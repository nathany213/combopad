# combopad
So basically, this is a 3x3 macropad, except it has a unique function: you can enter specific chains of digits to do "secret" functions (preset or customisable), just like entering a cheat code in a game.


## main components used
 - A SW10 Rotary encoder switch
 - An RP2040 Xiao Seed Studio microcontroller
 - 0.91" (i think) OLED Display
